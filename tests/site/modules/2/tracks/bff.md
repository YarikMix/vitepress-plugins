Пример трека BFF. Подстраницы: [Контракт](./bff/contract) и [Авторизация и CSRF](./bff/auth).

## Было и стало

Браузер вызывает BFF, а тот обращается к Go API.

## Cookie до и после

Сессия хранится в cookie BFF.

## Почему BFF

BFF объединяет серверные вызовы для клиента.

## Что меняется

Изменения затрагивают клиент, BFF, Go API и маршрутизацию.

### Фронт

Клиент вызывает процедуры tRPC.

### BFF

BFF проверяет сессию перед вызовом Go API.

### Go API

Go API принимает серверные запросы BFF.

### Infra

Прокси направляет запросы в BFF.

## Переключение

Клиент и сервер переходят на согласованный контракт.

## Две VPS

Прокси и API могут находиться на разных машинах.

## Ограничения

Обновление сессии требует согласования параллельных запросов.

## tRPC

Типы процедур связывают клиент с роутером BFF.
