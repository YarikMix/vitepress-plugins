# Миграция на BFF: авторизация и CSRF

Пример страницы трека о сессиях и защите запросов. См. [контракт](./contract).

## Cookie сессии

Cookie сессии передаётся BFF с запросами браузера.

## Как BFF обрабатывает вызов

BFF проверяет запрос, читает сессию и вызывает API.

## CSRF

Проверка происхождения запроса предшествует вызову процедуры.

## Сценарии

Ниже представлены типовые переходы состояния сессии.

### Вход

Успешный вход создаёт сессию.

### Запрос данных

Авторизованный запрос получает данные пользователя.

### Access истёк

BFF обновляет истёкший access-токен.

### Две вкладки

Параллельные запросы используют согласованное обновление сессии.

### Выход

Выход завершает сессию.

### Сессия кончилась

Без действующей сессии требуется повторный вход.

### Атака с чужого сайта

Запрос с недоверенного сайта отклоняется.

### Запрос с поддомена

Поддомен также проходит проверку происхождения.

### Переход по внешней ссылке

Переход открывает страницу приложения.

### Первый вход после переезда

После смены формата сессии пользователь входит заново.
