# Миграция на BFF: контракт

Пример контракта между клиентом, BFF и Go API. См. [авторизацию](./auth).

## Источники правды

Роутер описывает процедуры BFF, а спецификация API — вызовы Go.

## Что меняется в контракте Go

BFF обращается к Go API по согласованному серверному контракту.

## Команды

Проверки контракта запускаются до сборки клиента.

## Генерация Orval

Клиент API и схемы генерируются из спецификации.

## Роутер

Роутер объединяет процедуры по ресурсам.

## Процедуры экранов

Процедура экрана может объединять несколько запросов API.

## Ошибки

Ошибки API переводятся в ошибки процедур.

## Клиент

Клиент использует типы роутера.

## Какие вызовы BFF принимает

BFF принимает только объявленные процедуры.
