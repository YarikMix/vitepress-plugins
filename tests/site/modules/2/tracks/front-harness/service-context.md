# Контекст всего сервиса для агента фронта

Пример подстраницы трека с контекстом разработки сервиса.

## Цель

Дать агенту фронта описание связей сервиса.

## Контекст

Сервис включает клиент, API и инфраструктуру.

## Предусловие

Перед работой доступны необходимые репозитории.

## Шаг 1. Раздел «Сервис целиком» в `AGENTS.md` фронта

Описать назначение репозиториев и связи между ними.

## Шаг 2. Раскладка клонов и запуск

Показать расположение репозиториев и команды запуска.

## Шаг 3. Приёмка

Проверить запуск сервиса по описанным шагам.

## Шаг 4. Отчёт

Записать результат проверки и оставшиеся вопросы.

## Не входит

Изменения прикладной логики выполняются отдельными задачами.

## Кто ведёт таблицу

Владелец трека поддерживает описание актуальным.
